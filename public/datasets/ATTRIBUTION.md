# Demo Dataset Attribution

Images are bundled locally for the AIMachina XLab demo. Source files were downloaded from Wikimedia Commons as web-sized thumbnails.

The same attribution metadata is exposed in the app through `src/lib/demoDataset.ts` so users can open the original source pages from the demo UI.
